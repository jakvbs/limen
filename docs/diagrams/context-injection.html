## Capability (limen/templates/capability.md)
In Limen, many strong agents work in parallel, so engineering time is abundant: writing, testing, reviewing, and redoing a change take minutes. The owner's attention and the clarity of the system are scarce. Spend the time, not the attention: make the engineering decision yourself, choose the proper design over the patch, and prove it. Keep to the asked outcome.

3Tool result reminders

After a successful matching write, edit or bash · once per area until the agent reads the lines or the context compacts · appended to the tool result, so it stays in history

Write or edit under spec/

[limen] Specs: make your next tool call a read of templates/communication.md lines 19-43. They hold the rules for spec/features/planned/F010-x/ticket.md. Read them even if an earlier copy is in your context, then check this edit against them.

Write or edit of a file in the project that is not .md (every file of a multi-file edit)

They hold the rules for crates/alice/src/work/store.rs, including the sections `crates/alice`, Rust. Read them even if an earlier copy is in your context, then check this edit against them.

Bash with limen spawn, a ticket into spec/features/planned/, or a coordinator's git merge

[limen] Vision: make your next tool call a read of spec/vision.md lines 1-33. Read it even if an earlier copy is in your context, then check this step against it.

A styleguide heading that names a path (`crates/alice`) or a language (Rust, Frontend) applies only to matching files; other sections apply to every file. Lines the agent read with the read tool or cat are not named again. Group members also get peer progress here (hook/group-peer.ts).

Not injected: most tool results

read, grep, glob, test runs, every other bash command, a write or edit of a .md file outside spec/

The result reaches the model unchanged. A job makes hundreds of tool calls: a cue on each costs about 32 tokens a call, sits inside data the model parses, and turns into noise when it repeats. The F948 A/B also showed the short cue alone does almost nothing.
